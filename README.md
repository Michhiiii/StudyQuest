# StudyQuest

StudyQuest ist eine gamifizierte Lernplattform, die Studierende durch Quests, Achievements und Leaderboards motiviert, ihre Lernziele zu erreichen.

## Projektstruktur

Die Dokumentation ist in Kapitel aufgeteilt, die den Bewertungskriterien entsprechen. Jedes Dokument liegt sowohl als **Markdown** als auch als **PDF** vor. Die Markdown-Versionen sind zu bevorzugen, da dort die Formatierung und Bildanordnung besser dargestellt wird. Die PDFs befinden sich im Ordner `11_PDFs/` in derselben Ordnerstruktur.

| Ordner | Inhalt |
|--------|--------|
| `01_Projektskizze/` | Projektskizze |
| `02_Software_Development_Plan/` | Software Development Plan |
| `03_Anforderungsanalyse/` | Requirements & Use Cases |
| `04_Grobdesign/` | Analyseklassenmodell & Sequenzdiagramme |
| `05_Software_Detailed_Design/` | Softwarearchitektur, Design Document & Design Patterns |
| `06_Software_Verification_Plan/` | Software Verification Plan & Traceability Matrix |
| `07_Software_Quality_Assurance/` | SQAP / SQAR |
| `08_Aufwandsschaetzung/` | Aufwandsschätzung (Initial & Final) |
| `09_Code_Quality_VCS/` | Code Quality & Version Control |
| `10_Durchfuehrung/` | Besprechungsprotokolle, Review-Verfahren, Quellcode & Tests |
| `11_PDFs/` | Alle Dokumente als PDF (gleiche Ordnerstruktur) |
