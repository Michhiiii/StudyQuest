## 1 Branching-Strategie

Die Entwicklung erfolgt auf dem Branch `feature-version`, während `main` den stabilen Stand enthält. Alle Teammitglieder arbeiten über Pull/Push auf dasselbe GitHub-Remote-Repository.

## 2 Commit-Historie

Die Commit-Messages folgen einem einheitlichen, englischsprachigen Format und beschreiben klar die vorgenommenen Änderungen (z. B. *"Implement UC09: Quest notifications and reminders"*, *"Finalize all project documents for submission"*).
